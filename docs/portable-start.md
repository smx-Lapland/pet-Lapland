# 缪尔赛思桌宠 · Windows x64

将压缩包完整解压到一个可写目录，例如桌面的文件夹，双击 `Start.cmd`。包内自带 Python、桌宠依赖和本地 Whisper 识别模型。默认由 Windows 系统语音朗读。示例立绘是用内置 ImageGen 制作的同人图，配音是系统合成音。

**接入自己的模型**　右键角色打开「模型与项目」。已登录 DSH 的电脑可复用该机的 DeepSeek 凭据。也可以选择本机运行的 Ollama，或填写兼容 Chat Completions 的地址、模型 ID 和密钥环境变量名。为 Windows 用户设置新的环境变量后重新启动桌宠。

**修改角色**　右键打开「角色与迁移」。在四个页签里编辑角色名、说话风格、立绘、任务模板、对话模型和语音输出。只需一张基础立绘，也可为每个表情选择单独的图片。点击「另存并启用」可保留一个独立版本。「导出角色包」会保存当前编辑内容，接收方在同一窗口点「导入角色包」，检查后点「启用所选角色」。

**换语音**　「语音输出」支持系统音色、Edge、Azure、兼容 `/audio/speech` 的本地或远程服务，以及本地 Piper 模型。Piper 模型需要 `.onnx` 和对应的 `.onnx.json`，选择后两者会随角色包一起导出。专用拉普兰德 VITS / PocketTTS 服务依赖另外安装的角色模型。普通聊天和语音 API 使用各自的地址和凭据。

**连接 DSH**　需要在这台电脑安装 DSH CLI。右键「模型与项目」选择本机 DSH 项目及会话，普通聊天会结合最近三轮 DSH 摘录。右键「交给 DSH 执行」可以打字、语音填写，或从角色模板选择任务。点击执行后，DSH 在选中项目目录开一个新任务，沿用 DSH 自身的模型与权限；窗口里可以查看结果或停止任务。已发生的文件改动会保留。

桌宠历史、指定记忆与导入的角色位于本机用户目录。分享包使用单独生成的初始配置。角色包中的接口地址、提示词和任务模板会原样分享，密钥通过环境变量在接收方电脑上提供。

导入外部角色时，桌宠会清除包中指定的聊天和语音密钥变量名。需要自定义凭据时，在本机填好变量名，核对服务地址后点击「另存并启用」。远程 API 使用 HTTPS。本机模型可用 HTTP 回环地址，例如 `http://127.0.0.1:11434/v1`。
